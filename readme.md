## 🎯 Objetivo Principal

El objetivo principal de la materia **Programación IV** es el **Desarrollo Móvil**. Esta asignatura se enfoca en proporcionar las bases teóricas y prácticas necesarias para diseñar, construir y desplegar aplicaciones móviles modernas, escalables y eficientes, abarcando tanto el ecosistema nativo como las soluciones multiplataforma.

## 🚀 Tecnologías Estudiadas

A lo largo del curso, interactuamos con diversas herramientas y lenguajes clave para el ecosistema móvil y su integración con servicios backend. A continuación, un breve resumen de cada tecnología:

### Node.js

Es un entorno de ejecución de JavaScript del lado del servidor. En el contexto del desarrollo móvil, Node.js es fundamental para construir APIs RESTful rápidas y escalables, así como microservicios que actúan como el "backend" o cerebro de las aplicaciones móviles, gestionando bases de datos, autenticación y lógica de negocio.

### React Native

Es un framework de código abierto creado por Meta (Facebook) que permite desarrollar aplicaciones móviles reales y nativas para iOS y Android utilizando JavaScript y React. Su mayor ventaja es la capacidad de reutilizar gran parte del código entre ambas plataformas sin perder el rendimiento y la apariencia de una app nativa.

### Kotlin

Es un lenguaje de programación moderno, de tipado estático y multiplataforma. Fue declarado por Google como el lenguaje oficial y preferido (First-class) para el desarrollo de aplicaciones nativas en **Android**. Destaca por ser conciso, seguro (evita errores de referencias nulas) e interoperable al 100% con Java.

### Dart

Es un lenguaje de programación optimizado para el cliente, desarrollado por Google, diseñado específicamente para crear interfaces de usuario rápidas en cualquier plataforma. Destaca por su compilación anticipada (AOT) para un alto rendimiento en móviles y su compilación en tiempo de ejecución (JIT) que permite recargas rápidas durante el desarrollo.

### Flutter

Es el kit de desarrollo de software (SDK) de UI de código abierto de Google. Utiliza el lenguaje Dart y permite crear aplicaciones hermosas y compiladas nativamente para múltiples plataformas (Móvil, Web, Escritorio) desde una única base de código base. Destaca por su rendimiento fluido (60-120 fps) y su potente motor de renderizado propio.
